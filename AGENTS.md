# Project Backlog & Upcoming Features Roadmap

The following list tracks planned features and enhancements for future development. These items are noted for context and memory across development sessions, but are not currently active implementation tasks.

## To-Do List

- [x] **Starter Decks**: Add pre-saved starter decks to the Section Library.
- [x] **Digraphs Section**: Add a dedicated digraphs section in the section builder/library.
- [x] **Custom Section**: Allow users to create and configure custom sections.
- [x] **Section Days**: Customize which days a section appears on, with sequencer badges and day exclusion options.
- [x] **Template Choice Interface**: Redesign and update the template selection UI with custom template copier/importer.
- [ ] **School Name Metadata**: Add a "School Name" field after the "Prepared By" field in global settings.
- [ ] **Branding Options**: Support custom logos, theme colors, and institution branding.
- [ ] **Save Deck Option**: Enable users to save, load, and manage deck configurations (requires login / database integration).
- [ ] **Word Count Mismatch Warning**: Generate error warning if mild/spicy word count don't match in the Read a Word, Write a Word section.
- [ ] **Custom URL**: Support custom domain / custom URL routing (`dailydeck.app`).
- [ ] **Word Pool**: Implement a word pool linked to phonics level and revamp relevant sections for automatic word choices.
- [ ] **AI API**: Integrate an AI API for teachers to generate target sentences based on current phonics level.
- [ ] **Numeracy**: Introduce ability to produce numeracy daily reviews.
